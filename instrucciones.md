# Instrucciones de colaboración

Para participar en este repositorio:

1. Realiza un Fork del repositorio original.
2. Clona tu Fork en tu computadora.
3. Abre el proyecto en Visual Studio Code.
4. Realiza la modificación asignada.
5. Guarda tus cambios.
6. Ejecuta:

git status

7. Agrega los archivos modificados:

git add .

8. Crea un Commit:

git commit -m "Describe brevemente el cambio realizado"

9. Envía los cambios a tu repositorio:

git push

10. Desde GitHub crea un Pull Request hacia el repositorio original.
